# SolidWorks STEP 白屏急救 / SolidWorks Blank View Doctor

打开 STEP 后一片空白（白屏、白膜），但特征树里零件都在？多半不是文件坏了，
而是模型里混进了**几公里大的垃圾曲面**，SolidWorks 自动"缩放至适合"时视野被撑到几公里，
0.8 米的整车只剩 0.2 个像素 —— 看上去就是全白。

本工具连上正在运行的 SolidWorks，自动找出这些异常零件、藏起来、再把视图缩放好。
**不删任何东西、不保存文件、不关闭文档**，随时可撤销。

> 适用：SolidWorks + Windows + Python 3（本机在 SolidWorks 2026 上实测）。
> 判定规则针对机械件（小车、机械臂、夹具、电机等）调过，不适合厂房/桥梁这类本来就几百米的模型。

---

## 快速开始

1. 装依赖（只需一次）：

   ```bat
   pip install pywin32
   ```

2. 打开 SolidWorks，打开那个白屏的 STEP 文件。
3. 双击 `1-fix-blank-screen.bat`。
4. 看图形区 —— 应该已经能看到模型了。

后悔了：双击 `2-undo-last-fix.bat`。

---

## 文件说明

| 文件 | 作用 |
|---|---|
| `1-fix-blank-screen.bat` | **一键修复**：找出异常零件 → 隐藏 → 缩放至合适 |
| `2-undo-last-fix.bat` | 撤销上一次修复（把藏起来的零件重新显示） |
| `3-diagnose-only.bat` | 只出报告，一个字都不改模型 |
| `4-check-step-file.bat` | 导入前体检：把 `.step` / `.stp` 拖到它图标上，报告单位、零件数、真实尺寸、有没有跑飞的点（不用开 SolidWorks） |
| `step_blank_doctor.py` | 前三个的脚本本体（`--fix` / `--undo` / `--dry`） |
| `step_health_check.py` | 体检脚本本体 |

命令行用法：

```bat
python step_blank_doctor.py --fix     :: 修复
python step_blank_doctor.py --undo    :: 撤销
python step_blank_doctor.py --dry     :: 只诊断
python step_health_check.py "D:\path\model.step"
```

## 它怎么判断"垃圾零件"

三道闸，全过才动手：

1. **够大**：组件最大尺寸 > `max(3 米, 10×P90, 30×P50)`，明显不是正常零件；
2. **只认零件**：子装配体不参与判定（否则会连坐整个云台/底盘，把好东西一起藏了）；
3. **确实撑大了视野**：整体范围 ÷ 去掉异常件后的范围 > 8 倍。

任何一道不过，它就只报告、不动手，并给出别的排查方向。

> 为什么是"隐藏"而不是"压缩"：对子装配内部的零件调用 SolidWorks 的压缩接口，
> 实测会把状态卡死（压缩后解不回来），而隐藏 100% 有效、随时可逆。效果一样：图能看见。
> 想让它们彻底不参与计算，再在树里右键 → 压缩（手动，可选）。

## 白屏不止这一种原因

工具说"没发现超大垃圾面"时，按顺序试：

1. 键盘 `F`（缩放至适合）
2. 选中任意零件 → 右键 → **缩放至选择**（能看到东西就是取景问题）
3. 某个零件被摆到很远：选中 → 右键 → **隔离**，逐个排除
4. `视图 > 显示 > 带边线上色`
5. `视图 > 关闭剖面视图`

| 现象 | 原因 | 处理 |
|---|---|---|
| 全白、树里有零件、按 F 无效 | 超大垃圾面把视野撑到几公里 | 跑本工具 |
| 全白、按 F 后中心有个小点 | 零件被摆到很远 | 右键「缩放至选择」逐个隔离 |
| 树里只有一个"输入"特征 | 导入失败 | `工具 > 评估 > 输入诊断`，或关掉 3D Interconnect 重导 |
| 看见灰白面片但不是实体 | 导入的是曲面 | `插入 > 特征 > 缝合曲面`，或让对方给实体 |
| 形状对但尺寸差 1000 倍 | 单位选错 | 重导并选"由文件指定"单位；已导入的用 `插入 > 特征 > 缩放` |

## 导入设置建议（一次，省很多事）

`工具 > 选项 > 系统选项 > 导入`：

- STEP 勾上 **"输入诊断"**
- 关闭 **"启用 3D Interconnect"**（快，但畸形数据会静默出错；关掉走经典转换，出问题会明确报错）
- 导入单位选 **"由文件指定"**

---

## 一个很坑的点：3D Interconnect 是"虚拟文档"

用 3D Interconnect 打开的 STEP，那些 `.SLDPRT` / `.SLDASM` **磁盘上根本不存在**
（标题栏路径为空）。关掉 SolidWorks 就全没了，你隐藏/压缩的状态也一起没。

所以：导入完先 `文件 > 打包 (Pack and Go)` 存到自己的项目目录，再修。
以后打开保存好的装配，就不会再白屏。
